# knowledge — 内置知识库

关于 DSH 本身的机制事实、领域知识与操作手册。分层是为了**按任务只加载相关上下文**，
避免把整库塞进 agent 上下文。

| 层 | 目录 | 何时读 | 特点 |
| --- | --- | --- | --- |
| L0 基础事实 | `foundations/` | 涉及 DSH 机制时**必读** | 跨任务、稳定、小 |
| L1 领域知识 | `domains/<领域>/` | 任务匹配该领域时 | 按主题分 |
| L2 操作手册 | `runbooks/<操作>/` | 执行对应操作时 | 步骤化 |

路由规则：

- 目录名即主题：先 `ls` 看有哪些，再读对应目录的 README，最后读具体文件。
- L0 是「事实」（不可变机制），L1 是「知识」（可扩展），L2 是「步骤」（怎么做）。
- **一段事实只写一次**（single source of truth）；别处链接引用，不复制粘贴。
